# Journal

Use **Journal** for information you choose to keep: personal notes, memories and copies of documents your character has seen.

## Save a note or memory

Type in **Memories & notes**, then choose:

| Button | Where it goes |
| --- | --- |
| **Save note** | A local harness note. |
| **Save memory** | A local journal memory. |
| **Write memory in the game** | A separate game operation, presented for review before sending. |

You can also tell **Inner thoughts**, “Save what just happened in my memories” or “Add a note about the scout's warning.” Check the harness's save confirmation: discussing a fact alone does not automatically save it as a journal entry.

Local records belong to the selected profile and survive a fresh conversation. They are distinct from memories stored on the game character. Existing game memories appear here as character memories; preserving them does not make old mechanical rules current.

## Seen documents

The harness keeps copies of document text that has been observed or inspected. A saved copy can remain available after the physical item leaves your inventory. If different text is observed later, earlier versions are retained.

This is an archive of what the character has encountered, not a way to read unseen documents. A copy also does not mean your character still possesses the original item.

For an objective you intend to pursue, use [Quests](Quests.md). For mechanics that have changed, use [Rules & updates](Rules-and-updates.md). Back up the local data folder to preserve your journal between installations.
