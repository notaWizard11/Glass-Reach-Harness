# Glass Reach Harness — user guide

Glass Reach Harness connects your character, Codex and the live world. Use it to follow the story, decide what to do, act in the game and keep useful records between sessions.

**New here?** Follow the [quick-start](../../QUICKSTART.md) to install and connect first.

## The everyday loop

1. Open **Play** and check the selected character and connection status.
2. Read the storyboard or a catch-up briefing; expand the detailed records when needed.
3. Use **Inner thoughts** to consider options. Use **Act in game** when you want the character to do or say something.
4. Save important threads to Quests or Journal.
5. Choose **Set Away** before leaving, then **Return to Active · summarize** when you return.

The character dropdown and **Sync** button are at the top. The message composer stays available across sections. Selecting a profile changes its local records; profiles sharing a game token may also need **Settings → Reconnect selected character** to switch the active game seat.

Keep the harness server running and your PC awake for background work. **Live** controls ordinary feed polling; it does not switch off armed readied actions, explicit watches or autopilot. Generated prose is a summary of the evidence, not a replacement for the original game record.

This guide describes the current build. For setup, backups, updating and known limits, see the [project README](../../README.md). Examples in this guide are suggestions to type, not actions that have been carried out.
